## إعداد التواصل والبيانات

تظهر أزرار تواصل ثابتة للموقع والاتصال وواتساب على صفحات الموقع. عدّل قسم `quickContact` في `site-config.js` لتغيير بيانات الأزرار المشتركة، أو بيانات المكان نفسه لتخصيصها في صفحته. الرقم ورابط الخريطة الحاليان مضبوطَان للأماكن الثلاثة حسب المعلومات التي زودتنا بها.

أدخل الأسعار الفعلية ومحتوى المنيو والغرف والعروض والسياسات قبل النشر. حدّث النصوص التعريفية الموجودة في صفحات HTML لتطابق بيانات النشاط المعتمدة.

## التشغيل

يجب فتح الموقع عبر خادم ملفات محلي أو استضافته على الويب؛ لا تفتح ملفات HTML مباشرة بصيغة `file://` لأن المتصفح قد يمنع تشغيل الفيديوهات. لا توجد حزم بناء أو اعتماديات JavaScript مطلوبة. خط Readex Pro وDM Sans اختياري ويُحمّل من Google Fonts عند توفر اتصال إنترنت؛ تستخدم الصفحة خطوط النظام عند عدم توفره.
